# data/

| Path | Content | In git? |
|---|---|---|
| `sample/resumes_sample.json` | 45 **synthetic** resumes (9 role families x 5) in the exact Kaggle annotation format | yes |
| `raw/` | **put the real Kaggle file here** (see `docs/DATASET.md`) | no (git-ignored: resumes are personal data) |

All people, employers, colleges, e-mail addresses and phone numbers in the sample are fictional; they are generated by
`scripts/build_sample_resumes.py`. The sample exists so the pipeline, tests and demo run out of the box - its statistics
are not meaningful and no result computed on it should be reported as a finding about real candidates.
